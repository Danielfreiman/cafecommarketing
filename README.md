# Café com Marketing

Site institucional e portfólio audiovisual da agência Café com Marketing.

## Stack

- Next.js com App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- `next/image` para imagens responsivas e otimizadas
- Metadata API, sitemap, robots e dados estruturados para SEO

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Produção

```bash
npm run build
npm start
```

## Conteúdo

Os projetos, serviços, métricas e depoimentos estão centralizados em
`data/site.ts`, deixando a migração futura para Sanity, Payload, Strapi ou
WordPress Headless direta.

Antes da publicação oficial, substitua os contatos, métricas, membros da equipe,
depoimentos e mídias demonstrativas pelos dados reais da agência.
